# groundapp.live v3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace groundapp.live with one scrolling landing page led by a 3D "Breathe with Bodie" opening, matching GroundApp v2 exactly, plus the /play game, restyled secondary pages, a rewritten rulebook and a redesigned welcome email.

**Architecture:** Static HTML/CSS/JS on Cloudflare Pages (`site/`), Pages Functions unchanged except the welcome email template. Bodie is one ES module (`site/js/bodie-v3.js`) with a small controller API that the landing page drives. Copy and media are produced first as standalone artifacts (`docs/site-v3/copy.md`, `site/media/v3/`), then the page is built from them.

**Tech Stack:** HTML, CSS (brand kit v5 tokens), vanilla JS modules, three.js 0.186.1 via the existing import map, ffmpeg/cwebp for media, Node test runner for `test/`, studio-site-design tools for checks.

**Spec:** `docs/superpowers/specs/2026-10-30-site-v3-redesign-design.md` (read the "Changes after Collin's review" section last; it wins).

Note on TDD: this is a visual site. Behaviour that can regress silently (email render, signup tests, blog generator byte-match, site privacy check) is tested by the existing suites and commands named per task. Visual and motion quality is verified with the studio tools and screenshots, not unit tests.

### Bodie module API (`site/js/bodie-v3.js`, ES module)
```js
import { mountBodie } from '/js/bodie-v3.js';
const bodie = mountBodie(canvasEl, {
  pattern: { inhale: 5.5, hold: 0, exhale: 5.5, hold2: 0 }, // seconds; default Resonance
  interactive: true,          // press/hold on the canvas drives the breath
  onPhase(phase, remaining) {}, // phase: 'inhale' | 'hold' | 'exhale' | 'hold2'; remaining seconds (float)
});
bodie.setPattern({ inhale: 4, hold: 4, exhale: 4, hold2: 4 });
bodie.press(); bodie.release();      // manual: press = breathe in and keep filling, release = breathe out
bodie.react('wake' | 'wave' | 'lean' | 'cheer');
bodie.setStill(true);                // reduced motion / Low Power: hold a calm pose, glow still follows phase
bodie.destroy();
```
Patterns used on the page (from the app): Box 4-4-4-4, 4-7-8 (4 in, 7 hold, 8 out), Physiological sigh (2 in, 1 more in, 6 out: model as inhale 3 with a second-sip flag `sip: 1` at 2 s, exhale 6), Resonance 5.5/5.5.
